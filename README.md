# AI Fitness Coach

Учебное веб-приложение: модель **MediaPipe Pose Landmarker** распознаёт ключевые точки тела, а геометрические правила определяют фазы упражнения, считают повторения и дают простые подсказки. Камера и видео обрабатываются в браузере; платных AI API и сервера обработки нет.

## Возможности

- Камера в реальном времени, наложение скелета на Canvas.
- Приседания и отжимания: подсчёт полных циклов через конечный автомат, угол колена или локтя, сглаживание между кадрами.
- Подсказки о глубине, наклоне корпуса, неполном выпрямлении и положении тела (в зависимости от упражнения).
- Голосовые подсказки об ошибках на русском через Web Speech API. Звук можно включать и выключать в панели тренировки; выбор сохраняется в браузере. Доступность и произношение зависят от установленных русских голосов.
- Итог: количество повторений, правильных, с замечаниями, средняя оценка и основная рекомендация.
- Три слайда на главной с переключением стрелками и точками; значок приложения в браузере и на домашнем экране.
- **Демо без камеры** на искусственно заданных точках тела для проверки счётчика и интерфейса. Демо честно помечено как симуляция и **не демонстрирует распознавание моделью**.
- **Видеофайл** пользователя: тот же путь MediaPipe → анализатор, что и при работе камеры. Файл используется локально и не загружается на сервер.
- Модель и WebAssembly поставляются в `public/`; их не нужно загружать со стороннего CDN при открытии приложения.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`). Для камеры браузер запросит разрешение; в production необходим HTTPS. Если браузер отказал в разрешении, измените его в настройках сайта и нажмите кнопку запуска ещё раз.

Проверка:

```bash
npm test
npm run build
npm run preview
```

## Как работает AI

```text
Камера / локальный видеофайл
    ↓
MediaPipe Pose Landmarker (в браузере)
    ↓
Координаты и видимость суставов
    ↓
Угол и геометрия + сглаживание
    ↓
Конечный автомат упражнения
    ↓
Повторы, подсказки, статистика
```

Значение оценки техники — условный показатель по реализованным правилам. Полный цикл засчитывается при достижении нижней и верхней точек. Неполное движение даёт подсказку, но не учитывается как полный повтор. Для приседаний при обнаруженном сильном наклоне оценка полного повтора уменьшается на 18 пунктов; для отжиманий при нарушении линии тела на 20. Ошибки распознавания и неверный ракурс влияют на качество анализа. Во фронтальной проекции наклон корпуса и линия тела могут оцениваться хуже: для приседаний удобнее повернуться боком или вполоборота, для отжиманий — расположить камеру сбоку.

### Структура

- `src/pose/` — модель, контроль качества точек, геометрия, рисование и демо-точки.
- `src/exercises/` — типы и анализатор упражнений, без зависимости от React.
- `src/hooks/useTraining.ts` — запуск источника видео, цикл анализа, таймер и освобождение ресурсов.
- `src/components/TrainingView.tsx` — экран тренировки и результатов.
- `src/App.tsx` — выбор упражнения и режима.

Новые упражнения можно добавлять отдельным анализатором, сохранив общий интерфейс `ExerciseAnalyzer`.

## Развёртывание на Vercel

Импортируйте папку проекта в GitHub и затем в Vercel. Framework Preset: **Vite**; Build Command: `npm run build`; Output Directory: `dist`. Переменные окружения не нужны. Камера доступна на HTTPS-адресе Vercel.

Модель `pose_landmarker_lite.task` и wasm-файлы лежат в `public/`, поэтому публикуйте всю папку проекта, включая `public`. При первом запуске модель загружается в память устройства; GPU используется при доступности, иначе автоматически выбирается CPU.

## Ограничения

- Детектор работает синхронно; кадры ограничены примерно 12 FPS для снижения нагрузки. На слабых устройствах возможны краткие задержки интерфейса. Выделенный worker — возможное улучшение следующей версии.
- Правила техники приблизительны, основаны на 2D проекции тела, и не заменяют профессионального тренера или врача.
- Одновременно анализируется один человек. Для стабильного результата нужны хорошее освещение, всё тело в кадре и удобный ракурс.
- Демо использует синтетические точки. Для проверки реального ML без камеры выберите «Видеофайл» и откройте запись упражнения.
- Данные тренировки после закрытия вкладки не сохраняются.
- Если браузер не поддерживает синтез речи, текстовые подсказки продолжают работать, а переключатель звука недоступен.

Модель взята из [официального семейства MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js). Подробности API: [руководство MediaPipe для Web](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js).

# PlayFit Vision

Учебное веб-приложение: модель **MediaPipe Pose Landmarker** распознаёт ключевые точки тела, а геометрические правила определяют фазы упражнения, считают повторения и дают простые подсказки. Камера и видео обрабатываются в браузере; платных AI API и сервера обработки нет.

## Возможности

- Камера в реальном времени, наложение скелета на Canvas.
- Подготовка камеры с примером съёмки сбоку, проверкой точек и устойчивой исходной позиции. Для приседаний без веса ракурс проверяется отдельной эвристикой; при неопределённости можно подтвердить профиль вручную по примеру.
- Приседания и отжимания: подсчёт циклов через конечный автомат, сглаживание и переходы по времени, подтверждение замечаний достаточным наблюдением.
- Подсказки о глубине, наклоне корпуса, неполном выпрямлении и положении тела (в зависимости от упражнения).
- Голосовые подсказки об ошибках на русском через Web Speech API. Звук можно включать и выключать в панели тренировки; выбор сохраняется в браузере. Доступность и произношение зависят от установленных русских голосов.
- Итог: полные повторы, неполные и неоценённые попытки, замечания и разбор проверок с причинами нехватки данных. Общий процент техники не используется.
- Собственная цель: подходы, полные повторы и отдых. Пауза, отдых и следующий подход не учитывают движения; продолжение требует новой устойчивой исходной позиции. Значения нагрузки автоматически не назначаются.
- Локальная история завершённых сессий: детали подходов, сопоставимые наблюдения со знаменателями, удаление с подтверждением и JSON-экспорт. Демо исключено из личного прогресса; камера и записи разделены.
- Три слайда на главной с переключением стрелками и точками; значок приложения в браузере и на домашнем экране.
- **Демо без камеры** на искусственно заданных точках тела для проверки счётчика и интерфейса. Демо честно помечено как симуляция и **не демонстрирует распознавание моделью**.
- **Видеофайл** пользователя: тот же путь MediaPipe → анализатор, что и при работе камеры. Файл используется локально и не загружается на сервер.
- Модель и WebAssembly поставляются в `public/`; их не нужно загружать со стороннего CDN при открытии приложения.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://127.0.0.1:5173`). Для камеры браузер запросит разрешение; в production необходим HTTPS. Если браузер отказал в разрешении, измените его в настройках сайта и нажмите кнопку запуска ещё раз.

Проверка:

```bash
npm test
npm run build
npm run preview
```

## Как работает AI

```text
Камера / локальный видеофайл
    ↓
MediaPipe Pose Landmarker (в браузере)
    ↓
Координаты и видимость суставов
    ↓
Угол и геометрия + сглаживание
    ↓
Конечный автомат упражнения
    ↓
Повторы, подсказки, статистика
```

Полный повтор засчитывается после наблюдаемого движения от верхней точки через нижнюю и обратно, если обязательные проверки не имеют пропусков данных. Замечания о наклоне корпуса или линии тела сохраняются отдельно от исхода движения. Неглубокие движения и незавершённое выпрямление попадают в отчёт как неполные попытки. Если обязательные точки ненадёжны, попытка получает исход «недостаточно данных»; отсутствие замечаний не превращается в положительную оценку.

Перед первым движением удерживайте исходную верхнюю позицию около половины секунды. Подготовка не добавляет повторов. При потере наблюдения угол и техническая подсказка скрываются, озвучивание прекращается. Разрыв более 700 мс разделяет движение; после него нужна новая устойчивая исходная позиция. Видеофайл запускается после подготовки модели, проигрывается один раз и автоматически завершает анализ с сохранением незаконченной попытки. Темп измеряется по времени записи. Перемотка прерывает попытку; повторный запуск с экрана результата начинает анализ с нуля. Портретные и широкие записи отображаются без растяжения, скелет учитывает поля изображения. Камера, видео и демо используют один анализатор.

Ошибки распознавания и неверный ракурс влияют на результат. Правила приблизительны и не измеряют безопасность. Основной сценарий — приседания без веса строго сбоку: камера примерно на уровне таза, плечо, таз, колено и лодыжка ближней стороны в кадре весь подход. Дальняя сторона может быть закрыта; при неопределённости эвристики сверьтесь с примером. Для отжиманий также расположите камеру сбоку. Контракты результатов описаны в [docs/analysis-contract.md](docs/analysis-contract.md), параметры и ограничения — в [docs/camera-and-squat.md](docs/camera-and-squat.md).

Текущая подсказка показывает одно актуальное замечание с текстовой меткой связанного сегмента. Причина потери данных имеет приоритет над техникой. Предыдущая попытка разбирается отдельно: исход, причина отказа, доступный угол/длительность и результаты критериев. Итоги предлагают одну следующую задачу; при малом количестве данных — настройку съёмки. Голос имеет ограничение частоты и отменяется при смене сообщения/потере позы/завершении; текст работает и без него. [Политика подсказок, ограничения и ручная проверка](docs/actionable-feedback.md).

Перед запуском заполните собственную цель. Подход завершается при достижении числа полных оценённых циклов либо кнопкой; замечания не вычитают полный цикл, неполные и неоценённые попытки не повышают счёт цели. Во время паузы незаконченная попытка фиксируется как неоценённая с причиной паузы. Отдых заканчивается по таймеру, следующий подход запускается явно. Файл при паузе/отдыхе останавливается и продолжается с того же места; конец записи завершает всю сессию. [Контракты сессии, хранения, сравнения и ручная проверка](docs/training-history.md).

### Структура

- `src/pose/` — модель, контроль качества точек, геометрия, рисование и демо-точки.
- `src/exercises/` — типы и анализатор упражнений, без зависимости от React.
- `src/hooks/useTraining.ts` — запуск источника видео, цикл анализа, таймер и освобождение ресурсов.
- `src/components/TrainingView.tsx` — экран тренировки и результатов.
- `src/training/` — автомат сессии, схема локальной истории и показатели сопоставимых наблюдений.
- `src/components/HistoryView.tsx` — история, детали, экспорт и подтверждение удаления.
- `src/App.tsx` — выбор упражнения и режима.

Новые упражнения можно добавлять отдельным анализатором, сохранив общий интерфейс `ExerciseAnalyzer`.

## Развёртывание на Vercel

Импортируйте папку проекта в GitHub и затем в Vercel. Framework Preset: **Vite**; Build Command: `npm run build`; Output Directory: `dist`. Переменные окружения не нужны. Камера доступна на HTTPS-адресе Vercel.

Модель `pose_landmarker_lite.task` и wasm-файлы лежат в `public/`, поэтому публикуйте всю папку проекта, включая `public`. При первом запуске модель загружается в память устройства; GPU используется при доступности, иначе автоматически выбирается CPU.

## Ограничения

- Детектор работает синхронно; кадры ограничены примерно 12 FPS для снижения нагрузки. На слабых устройствах возможны краткие задержки интерфейса. Выделенный worker — возможное улучшение следующей версии.
- Правила техники приблизительны, основаны на 2D проекции тела, и не заменяют профессионального тренера или врача.
- Одновременно анализируется один человек. Для стабильного результата нужны хорошее освещение, всё тело в кадре и удобный ракурс.
- Демо использует синтетические точки. Для проверки реального ML без камеры выберите «Видеофайл» и откройте запись упражнения.
- Автотесты проверяют счёт на искусственных движениях при интервалах 33–200 мс и циклах 1.8–8 с. Это не измерение точности MediaPipe, ракурса или замечаний на людях: реальные записи ещё предстоит проверить.
- Только завершённые сессии сохраняются в localStorage этого браузера; синхронизации и восстановления незавершённой тренировки нет. Видео и координатный поток не сохраняются. При запрете/переполнении хранилища результат можно экспортировать с экрана итогов; повреждённая история не заменяется автоматически. Очистка данных браузера удалит результаты. Импорт резервной копии JSON пока не реализован.
- Если браузер не поддерживает синтез речи, текстовые подсказки продолжают работать, а переключатель звука недоступен.

Модель взята из [официального семейства MediaPipe Pose Landmarker](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js). Подробности API: [руководство MediaPipe для Web](https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker/web_js).

[Запуск и метрики](docs/validation/README.md), [формат набора](docs/validation/format.md), [памятка разметчику](docs/validation/annotator.md), [текущий отчёт](docs/validation/REPORT.md).

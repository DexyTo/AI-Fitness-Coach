# Перенос интерфейса в Figma

Дата: 22 октября 2026.

[Файл PlayFit Vision](https://www.figma.com/design/2eO470xqItyeH87QoBBv1C?node-id=22-2).

## Что сохранено

- 38 именованных desktop-фреймов основных страниц и состояний: главная гостя и аккаунта, каталог и детали упражнений, каталог и детали программы, конструктор, вход и регистрация, три шага знакомства, камера/видеофайл/демо, активная тренировка, пауза, результат, история, профиль, прогресс, достижения, настройки, испытания, дуэли, приглашение, рейтинг и участник.
- 9 мобильных макетов шириной 390 px: главная, упражнения, детали упражнения, программы, детали программы, подготовка тренировки, пустая история, вход, настройки.
- Нативные текстовые слои Manrope, векторные иконки, отдельные фотографии упражнений/оборудования, вложенные Auto Layout, экземпляры общих компонентов навигации, панелей, иконок и части кнопок. Захваты целого интерфейса не использованы как растровая подложка.
- Коллекция `PlayFit / UI`: 11 цветовых токенов актуальной светлой темы из `src/style.css`, 22 значения отступов/радиусов. Текстовые стили созданы по фактическим параметрам интерфейса.
- Учебные экраны аккаунта получены из отдельной SQLite в системной временной папке, созданной штатной командой `db:seed:demo`. Обычная база пользователя не наполнялась учебными записями. Активная тренировка и итог показаны на синтетическом демо; проверка распознавания на людях не выполнялась.

Это набор основных типов экранов и выбранных состояний, а не отдельный макет каждого элемента каталога, каждого раскрывающегося блока или каждой комбинации фильтров.

## Финальная уборка

После исчерпания лимита Figma MCP Starter работа продолжена в открытой пользователем вкладке Chrome. Через обычный редактор удалены 52 технических исходных захвата, desktop-фреймы разложены с интервалом 220 px, исправлена высота пустой гостевой истории. Мобильная главная повторно захвачена и восстановлена после обнаружения пустого первого захвата.

На всех девяти мобильных макетах нижняя навигация перемещена к нижнему краю длинного фрейма, чтобы не закрывать содержимое при просмотре в редакторе. В приложении она остаётся закреплённой в окне. Для знака бренда в 20 главных компонентах выбран `Noto Sans Symbols2 Regular`: это устраняет цветной emoji вместо одноцветного символа. Основной текст интерфейса остаётся Manrope.

Страницы файла: `01 · Desktop`, `02 · Mobile`, `03 · Компоненты и стили`. Основная ширина desktop — 1600 px, у отдельных дополнительных состояний — 1280 px. Это редактируемые дизайн-макеты; кликабельный прототип всех переходов в задачу не входил. Имена части компонентов сохраняют технические идентификаторы вариантов.

Библиотека содержит 179 главных компонентов, разложенных по четырём группам: «Иконки», «Кнопки», «Навигация», «Шапки экранов». Группировка сохраняет связи экземпляров с главными компонентами. В финале в Chrome визуально проверены главный desktop-экран и мобильная страница упражнения; знак бренда отображается одноцветным, нижняя навигация не перекрывает содержимое.

## Повторный перенос

1. Запустить приложение: `npm install`, затем `npm run dev` (в PowerShell при необходимости `npm.cmd`).
2. Для учебных экранов использовать отдельную `DATABASE_PATH` вне репозитория и `npm run db:seed:demo`; не отправлять личную историю или реальные записи камеры в Figma.
3. Получить новый одноразовый capture ID штатным Figma MCP. Открыть нужный маршрут с выданным `#figmacapture=…` и endpoint.
4. В `index.html` экспортный скрипт загружается только в Vite dev, только при явном capture-хеше и после появления `main`. При обычном открытии приложения и в production внешнего загрузчика Figma нет.
5. Проверить захват, собрать компоненты и стили, удалить технический исходник, проверить шрифты, редактируемость слоёв и композицию.

Локальные команды сборки и тестов не проверяют содержимое удалённого Figma-файла.

## Проверки проекта

- `npm run build` — успешно; экспортный загрузчик отсутствует в production-файлах.
- Первый `npm test` при параллельной сборке завершился тремя серверными таймаутами по 5 секунд. Повторный `npm test -- --maxWorkers=2` — 28 файлов, 365 тестов успешно.
- В Figma проверены структура и шрифт при сборке макетов; в Chrome дополнительно проверены выделение 38 desktop-фреймов, отсутствие исходных захватов, размер пустой истории и положения нижней навигации мобильных экранов.

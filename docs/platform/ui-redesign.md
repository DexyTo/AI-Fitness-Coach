# Адаптивный редизайн PlayFit Vision

Реализован 21 октября 2026 по двум предоставленным референсам в существующем React/TypeScript/Vite приложении. Светлая рабочая область, белые карточки, лаймовые основные действия, синие фильтры и графики. Подготовка и активная тренировка используют ту же светлую тему: окно камеры, счётчики, подсказки, управление и пауза не переключают палитру. Само изображение камеры или локального видео сохраняет исходные цвета. Backend, API, SQL-миграции и правила анализа не менялись. Новых зависимостей нет.

## Экраны и компоненты

- `AppNavigation`: боковая навигация на компьютере, нижняя на телефоне. Сохранены маршруты аккаунта, программ, редактора, испытаний, дуэлей, рейтинга и публичных участников. Верхний поиск открывает настоящий каталог с запросом.
- `DashboardViews`: новая главная с приветствием, текущим выбором упражнения, показателями истории, быстрыми упражнениями и переходами к программам. Новые `/exercises`, `/exercises/:id`, `/progress` дополняют прежние маршруты. Каталог содержит все десять уже существовавших упражнений, поиск и фильтры по мышечным группам.
- `WelcomeView`, `/welcome`: необязательное знакомство из трёх слайдов, начало и пропуск. На телефоне занимает экран целиком; не блокирует гостевую тренировку.
- `TrainingView`: подготовка, форма цели, ракурс и параметры упражнения, камера/видеофайл/синтетическое демо. После запуска на телефоне освобождается экран для видео, реальных точек, счётчика, времени, статуса наблюдения и текущей подсказки. Рядом с видео работают голос, пауза/продолжение и завершение. Пауза, отдых, потеря наблюдения и неудачный запуск оформлены в общей системе. Не добавлялся отдельный фиктивный датчик освещения.
- `ResultOverview`: общая композиция итогов и серверных деталей одиночного упражнения: превью, полные повторы или секунды, повторы без замечаний, цели подходов, отклонения по критериям и следующий шаг. Сохранены экспорт, повтор сохранения, подробности попыток/подходов, единицы удержания, замечания, неполные и неоценённые попытки. Неподтверждённый результат не скрывается кнопкой повтора.
- `HistoryAnalytics`: SVG-график полных повторов и полных повторов без замечаний, настоящие показатели и кольцевое распределение упражнений. История аккаунта и гостя получила миниатюры, фильтр упражнения, период записей, пустое состояние фильтра и прежние операции с данными.
- `PreferencesView`, `/settings`: рабочие локальные цели и план по умолчанию, существующая настройка голоса, настоящая проверка доступа к камере и помощь. Профиль на телефоне использует компактные строки навигации; на компьютере — карточки целей, плана и настроек. Редактирование имени/аватара и платформенные разделы доступны по раскрытию.
- Программы и редактор, обзор XP/достижений, соревнования, дуэли, рейтинг, вход/регистрация и системные состояния используют общие поверхности, поля, типографику и кнопки. Программы получили превью; мобильные фильтры раскрываются по кнопке.

Токены цветов, радиусов, тени и основных интервалов находятся в `src/style.css`. Адаптивная композиция и оформление экранов — в `src/redesign.css`. `ExerciseVisual` объединяет локальные фотографии и схемы дополнительных упражнений.

## Данные и контракты

- Гостевые результаты читаются через существующие `HistoryStore` и `loadPrograms`. При входе данные берутся только из `/api/history` текущего аккаунта. Импорт по-прежнему выполняется явно существующим сценарием.
- Неделя — последние 7 календарных дат, месяц — 30, год — 12 календарных месяцев, по локальному времени устройства. Это периоды графика истории; серверные сутки XP и периоды рейтинга Europe/Kyiv не менялись. Период списка записей выбирается отдельно; «Все даты» сохраняет доступ к старой истории.
- Одна программа считается одной тренировкой. Повторы и распределение упражнений включают её фактически сохранённые шаги. Будущие незаписанные шаги не превращаются в выполненные упражнения. Синтетическое демо исключено из графиков. Камера, видео и импорт сохраняют своё происхождение; данные учебного аккаунта явно обозначены.
- Кольцо «Цели подходов» показывает достигнутые цели относительно запланированных подходов записанных упражнений. Это **не процент техники или безопасности**. Отсутствие знаменателя показывается как «—». Секунды удержания не складываются с повторами.
- Локальные предпочтения: `playfit.preferences.<userId>` или `playfit.preferences.guest`. Сохраняются строки `sets`, `reps`, `restSeconds` и личный ориентир `goal`; при чтении проверяются диапазоны. План подставляется в новую одиночную тренировку и остаётся редактируемым. Настройки не меняют снимок программы или правила анализа. Голос использует прежний ключ устройства `playfit-vision-voice-enabled`.
- Уведомления с расписанием, персональная оценка сложности и чувствительность анализа в исходном приложении отсутствовали. Неработающих переключателей для них не добавлено. Кнопка с колокольчиком открывает информационную панель без выдуманного счётчика уведомлений. Разрешение камеры запрашивается браузером; успешная проверка сразу останавливает тестовый поток.

## Запуск и проверки

```sh
npm install
npm run dev
```

Обычно клиент доступен на `http://127.0.0.1:5173`, API — `127.0.0.1:3001`. Новых команд миграции нет. Обычный запуск сохраняет данные и применяет уже существующие миграции.

- `npm test`: **358/358**, 26 файлов. Пять новых проверок агрегации охватывают границы периодов, исключение демо/будущих записей, видео, пустые данные, календарный год и учёт программы одним событием.
- `npm run build`: серверная и клиентская типизация, Vite — успешно. Отдельного lint-скрипта в проекте нет. Vite предупреждает о размере основного JS-чанка около 513 kB; сборка успешна.
- `git diff --check`: успешно.
- Фактический IAB: измеренные ширины **390, 960, 1440 CSS px**. Проверены основные маршруты и отсутствие горизонтального переполнения. Просмотрены главная, каталог, детали, подготовка, активная сессия/пауза/потеря позы, итоги, история, профиль/настройки, программы, редактор, обзор и рейтинг. Проверены поиск, фильтры, онбординг, сохранение настроек и их применение, гостевой повтор/пауза/продолжение/сохранение.
- Для аккаунта использована отдельная `.validation-build/ui-redesign.sqlite`, наполненная штатным явно учебным seed: вход, чтение серверной истории, фильтры/периоды/распределение, запись результата синтетического демо с подтверждением сохранения и отсутствием XP. Основная база учебным seed не наполнялась.
- Снимки проверки находятся в игнорируемой `.validation-build/ui-redesign/`: `home-mobile.png`, `home-desktop.png`, `profile-desktop.png`, `history-desktop.png`, `results-desktop.png`, `training-mobile.png`. Это скриншоты настоящего интерфейса; учебные записи и синтетическая тренировка не подтверждают работу распознавания на людях.

## Материалы и ограничения

После исправления темы окна тренировки повторно прошли `npm test` (358/358), `npm run build` и `git diff --check`. В браузере проверены подготовка камеры и видеозаписи, активное синтетическое демо, пауза/продолжение и потеря наблюдения на ширинах 390 и 1440 CSS px; горизонтального переполнения нет. Снимки — `.validation-build/training-light/`. Это проверка интерфейса, без оценки распознавания на людях. Команда локального запуска прежняя: `npm run dev`.

Четыре изображения сгенерированы встроенным imagegen и сохранены в `public/images/`; [промпты и происхождение](../../public/images/README.md). Скриншоты референсов не используются как фон интерфейса. Для остальных шести упражнений предусмотрены собственные SVG-схемы поз, а не неподходящие фотографии.

Реальная камера, локальные видео с людьми, фактическая работа голосового синтеза и внешняя точность распознавания в этой задаче не проверялись. Сохранён существующий MediaPipe/анализатор; оценка освещения не имитируется. Настройки хранятся на устройстве и не синхронизируются между компьютерами. Публикации и деплоя нет. Следующие изменения — по отдельной задаче.

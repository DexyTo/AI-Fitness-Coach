# Памятка тренеру-разметчику

Все нижеописанные 2D-критерии **предварительные, не проверены специалистом в рамках проекта и не являются клинически подтверждёнными**. Роль тренера — независимо описать видимое движение, проверить пригодность операционных определений и отметить ограничения. Не диагностируйте травмы, не выводите безопасность из отсутствия замечаний. Не просите человека специально воспроизводить опасное движение ради записи.

## До разметки

Проверьте разрешение на использование, вариант упражнения и ракурс. Основной сценарий: приседания без веса, профиль, камера примерно на высоте таза, плечо/таз/колено/лодыжка одной стороны в кадре. Отжимания — отдельный регрессионный набор `pushup-side`, видны плечо/локоть/запястье и таз/лодыжка. Не размечайте неизвестное упражнение текущими правилами.

Сначала просмотрите исходную запись без точек, счётчика и замечаний алгоритма. Разметьте границы и исходы, затем критерии и начало отклонений. Просмотр по кадрам допустим; исходные таймкоды всегда от начала файла. В начале желателен 1–2-секундный покой в верхней позиции. Начатый до наблюдаемой верхней позиции подъём не является полным новым циклом протокола; отметьте это в замечаниях или как неоценимый участок.

## Операционные определения

| Событие/критерий | Что размечать по видео |
| --- | --- |
| Попытка | Значимое намеренное опускание от наблюдаемой верхней позиции. Начало — первый видимый кадр этого опускания; конец — первый видимый возврат в верхнюю позицию, новый спуск после незавершённого подъёма, потеря наблюдения или конец файла. Малые колебания покоя не считать отдельными попытками; сомнение пояснить |
| `complete` | Полный видимый спуск до согласованной нижней позиции и возврат наверх; полнота наблюдения обязательна. Замечание корпуса возможно при полном повторе |
| `incomplete` | Движение видно достаточно хорошо, но нижняя позиция не достигнута либо возврат наверх не завершён до нового спуска/конца |
| `insufficient_data` | Попытка видна, но из-за ракурса, перекрытия, обрезки, размытия нельзя надёжно установить исход. Доступные замечания сохраняются отдельно |
| `depth` | Наблюдаемый разворот/подъём до согласованной нижней позиции. Для первичного сопоставления правила кода: проекционный угол таз–колено–лодыжка <= 102° (squat), плечо–локоть–запястье <= 98° (pushup). При отклонении onset — первый кадр подтверждаемого разворота вверх без достижения позиции, а не начало всего спуска |
| `extension` | Наблюдаемый незавершённый возврат в верхнюю позицию перед новым спуском или окончанием файла. Предварительный порог кода >= 158° колена/локтя. Onset — новый спуск без возврата либо конец файла; не считать каждый обычный согнутый сустав во время движения ошибкой выпрямления |
| `lean` | Устойчиво наблюдаемый наклон линии плечо–таз относительно вертикали; код использует > 43° на протяжении >= 300 мс. Это описание проекции, а не универсальный допустимый наклон для всех людей. Onset — начало непрерывного участка, которое можно установить по исходным кадрам |
| `line` | Устойчивый видимый излом линии плечо–таз–лодыжка; код использует отклонение от 180° > 27° на протяжении >= 300 мс. Onset — начало такого участка. Не подставлять другую сторону тела при перекрытии |

Числа приведены для объяснения предварительного поведения системы, а не для принудительного согласия эксперта с алгоритмом. Для независимой разметки специалист сначала фиксирует наблюдаемое отклонение по согласованному протоколу; если операционное определение/порог не подходит, записывает возражение в `note` и протоколе пересмотра. Изменять правила можно только на calibration, после чего заморозить новую версию и переразметить затронутые случаи независимо. Не ставьте «deviation» только потому, что такое замечание показала программа. Не используйте landmarks MediaPipe как эталон.

## Неопределённость и разногласия

- Различайте «отклонение не видно» и «видно, что отклонения нет». Первое — `unassessed` с причиной, второе — `passed`.
- При одном закрытом критерии сохраните попытку и остальные критерии; у закрытого поставьте `unassessed` и обязательный `note`. Глобальные `unassessable` предназначены для участков, где нельзя даже надёжно перечислить попытки; их нельзя использовать для сокрытия плохих прогнозов.
- При закрытой дальней стороне ближняя полная цепочка может быть достаточной. Неизвестный ракурс отличается от отсутствия суставов. Смена анатомической стороны внутри одного движения не доказывает непрерывное наблюдение.
- Для пограничных углов, одиночного размытого кадра и спорной длительности отметьте неопределённость, а не округляйте в удобную сторону. Onset оставляйте пустым, если нельзя локализовать начало; не придумывайте точность до миллисекунды.
- Два разметчика независимо оценивают как минимум заранее выбранную долю записей и все спорные случаи. Сохраните исходные версии, затем согласуйте итог с третьим специалистом/совместным просмотром; укажите revision. Не подглядывайте в прогнозы во время согласования.
- Отдельно сохраните межэкспертное согласие: число расхождений исходов, TP/FP/FN замечаний между разметчиками, распределение разности границ. Если согласие низкое, сначала уточните определения на calibration. Контроль не используйте для настройки.

Перед передачей файла убедитесь, что все критерии явно заполнены, попытки упорядочены без перекрытий, спорные моменты объяснены, `source` и `reviewer` соответствуют фактическому источнику. Анонимный код разметчика/специалиста при необходимости хранится только в частном журнале, без имени в репозитории.
